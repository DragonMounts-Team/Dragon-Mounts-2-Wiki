#Troubleshooting

I can't find the add-on in my world's settings

Confirm Minecraft finished importing the file, then check the world's Resource Packs and Behavior Packs lists. If that does not work, please retry or get in hold of the Developers on Discord or the supplied download links.

Dragons or items are missing

Check that every pack included with the download is enabled for the world. If it persists do a fresh install

The file will not import

Confirm your Minecraft version is supported by the selected release file, then follow the official installation notes.

A mechanic differs from this guide

Check the notes attached to your exact release file, then report the difference, if the features behaves as intended but the wiki has give false information or old information please contact us on Github or Discord.

Still stuck? Ask on Discord or report it on GitHub
